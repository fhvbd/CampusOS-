# CampusOS 项目目录结构设计

版本：V1.0
关联文档：03_技术架构设计.md / 05_系统详细架构设计书.md

---

# 一、设计原则

1. **前后端分离**：frontend（Flutter）与 backend（FastAPI）完全独立，通过 API 通信。
2. **模块解耦**：每个业务模块（首页、通知、课表、日程、AI）在目录上各自独立，互不影响，方便后续扩展或裁剪。
3. **文档先行**：docs/ 目录保存全部设计文档，编码前必须先补全对应文档。
4. **V1 最小化**：AI、爬虫（crawler）等 V0.5 以后才启用的目录，V1 阶段先建空目录占位，不实现具体逻辑，避免功能膨胀。

# 三、前端目录结构（frontend/）

```
frontend/
├── lib/
│   ├── main.dart                 # 应用入口
│   ├── app.dart                  # 全局路由与主题装配
│   │
│   ├── pages/                    # 页面（按业务模块划分）
│   │   ├── home/                 # 首页：今日课程、待办、通知、AI建议
│   │   ├── schedule/              # 课表中心：课表展示、课程详情、考试提醒
│   │   ├── notice/                # 通知中心：列表、详情、收藏、已读
│   │   ├── ai/                    # AI学习助手（V0.5 起启用）
│   │   └── profile/               # 我的：个人信息、设置
│   │
│   ├── widgets/                  # 可复用 UI 组件（卡片、列表项、底部导航栏等）
│   │
│   ├── services/                 # 网络请求封装（对应 07_API接口设计书 各模块）
│   │   ├── auth_service.dart
│   │   ├── course_service.dart
│   │   ├── notice_service.dart
│   │   ├── task_service.dart
│   │   ├── ai_service.dart        # V0.5 起启用
│   │   └── settings_service.dart
│   │
│   ├── models/                   # 数据模型（与数据库设计书表结构对应）
│   │   ├── user_model.dart
│   │   ├── course_model.dart
│   │   ├── notice_model.dart
│   │   ├── task_model.dart
│   │   └── ai_record_model.dart   # V0.5 起启用
│   │
│   ├── utils/                    # 工具类（本地缓存、日期处理、请求拦截等）
│   ├── routes/                   # 路由配置
│   ├── theme/                    # 主题与样式（对应 08_UI原型设计书 设计原则）
│   └── config/                   # 环境配置（API 地址等）
│
├── assets/                       # 图片、图标等静态资源
├── test/                         # 单元测试 / Widget 测试
└── pubspec.yaml
```

```

│   │   ├── course_service.py

│   ├── models/                   # ORM 数据模型（对应 06_数据库设计书）

│   │   ├── course.py
│   │   ├── exam.py                 # 暂缓，V0.5 后加入
│   │   ├── task.py
│   │   ├── notice.py
│   │   ├── ai_record.py            # 暂缓，V0.5 后加入
│   │   └── settings.py
│   │
│   ├── database/                 # 数据库连接与初始化

│   │

│
```

# 六、命名规范

- 目录名：全小写，单词间用下划线分隔（如 `ai_records`）。
- Dart 文件：`snake_case.dart`，类名使用 `PascalCase`。
- Python 文件：`snake_case.py`，类名使用 `PascalCase`。
- 数据库表名、字段名：全小写下划线风格，与 06_数据库设计书 保持一致。
- API 路径：`/api/{模块}/{动作}`，与 07_API接口设计书 保持一致。
