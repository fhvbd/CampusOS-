# CampusOS

AI Powered Campus Operating System

---

## 项目简介

CampusOS 是一个面向大学生的智能校园助手。

目标：

整合校园系统

统一信息入口

引入AI能力

提升学习效率

---

## 核心功能

- 校园通知中心
- 智能课表
- 作业管理
- 日程管理
- AI学习助手
- 奖学金雷达
- 实习雷达
